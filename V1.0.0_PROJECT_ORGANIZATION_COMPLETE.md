### 2. Updated Build System

**build/build.zig:**
- Updated all paths to reference `../src/`
- Main entry point: `../src/main.zig`
- Test paths: `../src/{lexer,parser,memory,interpreter}.zig`

**build/install.sh:**
- Builds from `$PROJECT_ROOT/src/main.zig`
- Installs to `/opt/mbl/bin/mbl` (preferred)
- Creates symlink: `/usr/local/bin/mbl`
- Copies examples to `/opt/mbl/share/examples/`
- Fallback: `/usr/local/bin/mbl`
- Maintains encryption setup in `/etc/mbl/mbl.conf`

## Production Installation Paths

### System-Wide Installation

```
/opt/mbl/                   # Main installation directory
├── bin/
│   └── mbl                # Main executable
└── share/
    └── examples/          # Example programs

/usr/local/bin/mbl         # Symlink to /opt/mbl/bin/mbl

/etc/mbl/                   # System configuration
└── mbl.conf               # System salt and config

~/.config/mbl/              # User configuration (fallback)
└── mbl.conf               # User-specific config

~/.mbl_secrets.json         # User secrets (encrypted)
```

## Building and Installing

### Using New Structure

```bash
# Build
cd build
./install.sh

# Or manually:
cd build
zig build-exe ../src/main.zig -O ReleaseFast --name mbl
```

### Testing New Structure

```bash
# Test a simple program
echo 'program.write("Hello from v1.0.0!")' > /tmp/test.mbl
/opt/mbl/bin/mbl /tmp/test.mbl

# Or with symlink:
mbl /tmp/test.mbl
```

# MBL v0.18.0 - File Operations & Advanced I/O

## Overview

Version 0.18.0 adds comprehensive file system operations to MBL, enabling business applications to manage files, traverse directories, and access file metadata with simple, business-readable syntax.

## New Features

### Directory Operations

#### `program.dir_list(path)` - List Directory Contents
Returns a list of records with file/directory information:
```mbl
entries = program.dir_list("/data")
for entry in entries
    program.write(entry.name + " - " + entry.type)
```

Each entry contains:
- `name` - File or directory name
- `type` - "file", "directory", "symlink", or "other"

#### `program.dir_create(path)` - Create Directory
Creates a new directory:
```mbl
program.dir_create("/backup/2025-09-29")
```

#### `program.dir_delete(path)` - Delete Directory
Deletes an empty directory:
```mbl
program.dir_delete("/temp/old_data")
```

#### `program.dir_exists(path)` - Check Directory Exists
Returns boolean indicating if directory exists:
```mbl
if program.dir_exists("/backup")
    program.write("Backup directory ready")
```

### File Operations

#### `program.file_exists(path)` - Check File Exists
Returns boolean indicating if file exists:
```mbl
if program.file_exists("/data/invoices.csv")
    program.write("Invoices file found")
```

#### `program.file_copy(source, dest)` - Copy File
Copies a file to new location:
```mbl
program.file_copy("/data/report.pdf", "/backup/report_2025.pdf")
```

#### `program.file_move(source, dest)` - Move/Rename File
Moves or renames a file:
```mbl
program.file_move("/temp/data.csv", "/processed/data_final.csv")
```

#### `program.file_delete(path)` - Delete File
Deletes a file:
```mbl
program.file_delete("/temp/temporary_data.txt")
```

#### `program.file_info(path)` - Get File Metadata
Returns record with file information:
```mbl
info = program.file_info("/data/report.pdf")
program.write("Size: " + info.size.text() + " bytes")
program.write("Type: " + info.type)
program.write("Modified: " + info.modified.text())
```

Returns:
- `size` - File size in bytes (Number)
- `type` - File type: "file", "directory", "symlink", "other" (Text)
- `modified` - Last modification time as Unix timestamp (Number)

## Business Use Cases

### Automated Backups
```mbl
backup_dir = "/backup/" + program.date.today().text()
program.dir_create(backup_dir)

files = ["invoices.csv", "customers.json", "orders.csv"]
for file in files
    if program.file_exists("/data/" + file)
        program.file_copy("/data/" + file, backup_dir + "/" + file)
```

### File Organization
```mbl
entries = program.dir_list("/documents")
for entry in entries
    if entry.type = "file"
        if entry.name.ends_with(".pdf")
            program.file_move("/documents/" + entry.name, "/documents/pdfs/" + entry.name)
```

### Storage Monitoring
```mbl
files = program.dir_list("/data")
for file in files
    if file.type = "file"
        info = program.file_info("/data/" + file.name)
        if info.size > 10000000  # 10MB
            program.write("⚠️ Large file: " + file.name)
```

### Data Processing Pipeline
```mbl
# Check for new files to process
if program.file_exists("/incoming/data.csv")
    # Process the file
    data = program.import("/incoming/data.csv")
    # ... processing logic ...

    # Move to processed folder
    program.file_move("/incoming/data.csv", "/processed/data_" + program.date.now().text() + ".csv")
```

## Implementation Details

### Architecture
- All operations use Zig's `std.fs` module for cross-platform file system access
- Absolute paths required for all operations
- Error handling returns MBLValue with error messages
- Memory-safe with proper cleanup of all allocations

### Error Handling
Operations return:
- Boolean `true` for successful operations
- Boolean `false` or error message Text for failures
- Empty directory required for `dir_delete()`
- File must exist for metadata operations

### Performance
- Directory listing is efficient with iterator-based traversal
- File operations use OS-level system calls
- Metadata access uses stat() for minimal overhead
- No unnecessary file content reading
